# v0.6 — Canonical Examples and Extension Model

## Status

Exploratory draft. This layer cannot freeze before v0.1–v0.5 and independent
review. Repository release v0.6.0 does not close decision D-001 or establish
stable conformance. Artifacts continue to declare `spec_version: "0.4-draft"`;
v0.6 identifies a specification layer, not a new artifact schema.

## Documents

- [Extension model](extension-model.md): placement, namespaces, preservation,
  evolution and third-party publication requirements.
- [Canonical examples](examples.md): minimal and advanced artifacts, negative
  controls and expected validation behavior.
- [Example manifest](examples/manifest.json): offline fixture paths and outcomes.
- [Acceptance criteria](acceptance-criteria.md): remaining review gates.

The v0.4 schemas and semantic conformance rules remain authoritative for artifact
validation. These examples do not add runtime objects, event names or dependency
requirements. Provenance objects and a portable conformance suite remain v0.6.x.
